## Что покрывают тесты

- Все десять пунктов G0 требуют основания; красный маршрут блокирует генерацию.
- Каждый из четырёх пропусков изысканий даёт жёлтый маршрут без SLA.
- 27 сочетаний размеров/вариантов: положительные площади, покрытие всей территории, отсутствие пересечений, соблюдение границ.
- Сверка денежного потока с прибылью, стресс-сценарий, отсутствие окупаемости у убыточной модели.
- Серверные роли, запрет самопроверки, запрет изменения данных экспертом и администратором, закрытый экспорт без сессии.
- Запрет принятия до проверки, возврат на доработку, новый расчёт после возврата, устаревший revision и согласование.
- Origin/CSRF, неверные параметры, тело запроса свыше 32 КБ, выход из сессии.
- Три сквозных HTTP-сценария: зелёный, жёлтый и красный.

Браузерный полный цикл дополнительно пройден на «Демо · Лесной квартал». JSON-экспорт проверен HTTP E2E. Сквозные тесты используют реальные API и SQLite, без подмены БД.

## Границы

Не выполнены pentest, полный WCAG-аудит, скринридер, нагрузочное тестирование, проверка всех мобильных браузеров, установка PWA на телефон, реальная потеря сети и независимая профессиональная проверка мастер-плана. Восемь отчётов правил не являются восемью запущенными LLM. Нормативная допустимость размеров участков, дорог и планировки не проверена.
